# bioinformatics MegaLinter Flavor

![Docker Image Size (tag)](https://img.shields.io/docker/image-size/oxsecurity/megalinter-bioinformatics/beta)
![Docker Pulls](https://img.shields.io/docker/pulls/oxsecurity/megalinter-bioinformatics)

## Description

Optimized for bioinformatics projects

## Usage

- [GitHub Action](https://megalinter.io/beta/installation/#github-action): **oxsecurity/megalinter/flavors/bioinformatics@beta**
- Docker image: **oxsecurity/megalinter-bioinformatics:beta**
- [mega-linter-runner](https://megalinter.io/beta/mega-linter-runner/): `mega-linter-runner --flavor bioinformatics`
